Preguntas Frecuentes

Todo lo que necesitas saber sobre el funcionamiento de Apex.

¿Cómo protege Apex mis datos personales?

Mediante aislamiento Air-Gapped y cifrado AES-256. Al procesarse todo de manera local en tu equipo, la información nunca abandona tu dispositivo.

¿Qué requisitos de hardware son necesarios?

Está optimizado para funcionar con fluidez en equipos equilibrados como portátiles y equipos de escritorio con procesadores Intel Core i5.

¿Cómo se conecta la interfaz con el modelo?

La interfaz web interactúa directamente a través de APIs locales con motores de ejecución como Ollama sin depender de servidores remotos.

¿Dónde puedo utilizar Apex actualmente?

Puedes acceder al entorno web interactivo alojado en GitHub Pages, mientras se preparan los paquetes nativos para las distintas plataformas.
